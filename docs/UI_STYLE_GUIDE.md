# UI Style Guide

- Primary: `#00327D`.
- Secondary Blue: `#0E52B7`.
- Background: `#F8F9FF`.
- Surface: `#FFFFFF`.
- Critical accent: `#BA1A1A`.
- Sidebar width: 260px.
- Card radius: 14px.
- Buttons and inputs: 8px radius.
- Font fallback: Segoe UI, Inter, Arial.
- Red is used only for critical priority, high risk and destructive actions.
