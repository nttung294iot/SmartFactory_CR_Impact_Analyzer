# Hướng dẫn sử dụng

## 1. Dashboard

Dashboard hiển thị tổng số CR, CR chờ phân tích, CR đã phân tích và CR đã được BA xác nhận. Chọn **New Change Request** để bắt đầu hoặc **Load Sample Request** để tải CR-001.

## 2. New Change Request

Nhập các trường bắt buộc: Title, Requester, Priority, Change Description, Business Reason và Expected Behavior. Có thể lưu Draft hoặc nhấn Analyze.

## 3. Analysis Workspace

- **Overview**: xem tóm tắt.
- **Related Documents**: giữ hoặc bỏ tài liệu liên quan.
- **Impact Scope**: điều chỉnh module và mức tác động.
- **Artifacts To Review**: xác định tài liệu cần Review/Update/Create.
- **BA Suggestions**: trả lời câu hỏi, cập nhật rủi ro và bản nháp.
- **Review & Export**: xác nhận kết quả và xuất DOCX/XLSX.

## 4. Knowledge Base

Tìm kiếm, lọc và xem chi tiết artefact. Trang này chỉ đọc để giữ demo ổn định.

## 5. History

Mở lại CR, tiếp tục review, phân tích lại, export hoặc xóa bản ghi.
