# Kịch bản demo 5-7 phút

1. Mở Dashboard và giới thiệu mục tiêu prototype.
2. Chọn **Load Sample Request** để tải CR-001.
3. Kiểm tra form và nhấn **Analyze**.
4. Tại Analysis Workspace, trình bày tài liệu liên quan và 3 module bị ảnh hưởng.
5. Chỉnh BA Note hoặc loại một tài liệu không phù hợp.
6. Mở BA Suggestions để trình bày câu hỏi, rủi ro và bản nháp.
7. Chọn Review Status **Confirmed**, nhập reviewer và lưu.
8. Xuất Impact Analysis Report và Traceability Matrix.
9. Mở History để chứng minh kết quả được lưu lại.
