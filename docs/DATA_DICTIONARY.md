# Data Dictionary

## Change Request

Các trường chính: `id`, `title`, `requester`, `request_date`, `priority`, `change_type`, `description`, `reason_for_change`, `current_behavior`, `expected_behavior`, `affected_process`, `initial_module`, `status`.

## Artefact

Các trường chính: `id`, `type`, `title`, `description`, `module_ids`, `role_ids`, `keywords`, `tags`, `related_artifact_ids`, `status`, `version`, `source`, `language`.

## Analysis Result

Các nhóm dữ liệu: preprocessing, retrieved artefacts, rule matches, impacted modules, artefacts to review, draft requirements, risks, clarifying questions, assumptions, dependencies, traceability matrix và BA review status.
